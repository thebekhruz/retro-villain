# Бухгалтер: журнал и остатки

## Подтверждённые правила

- «В сейфе» в апрельской ведомости — отложено под дивиденды, ещё не выдано собственнику (подтверждено пользователем).
- Карточка дивидендов показывает остаток резерва, не сумму всех записей «Взято дивидендов».
- USD — реальные доллары, не пересчёт остатка сумов по курсу.
- На компьютере журнал находится под опоздавшими, показатели — справа. На телефоне блоки идут последовательно.

## Операции

В журнале выбираются категория, зависимый тип, наименование и сумма. Сохранение выполняется кнопкой «Записать», после ответа сервера загружаются новые остатки.

| Операция | Деньги на расходы, UZS | Другой остаток |
| --- | --- | --- |
| Обычный расход, зарплата, выдача Шоху | Уменьшение | Выдача Шоху увеличивает его подотчёт |
| Отложить в сейф | Уменьшение | Увеличение резерва дивидендов |
| Выдать собственнику из сейфа | Без повторного списания | Уменьшение резерва |
| Поступили / выданы реальные USD | Без изменения | Изменение USD |
| Принята закупка от Шоха | Без повторного списания | Уменьшение подотчёта по накладной |
| Дивиденды напрямую из кассы | Уменьшение | Резерв не меняется |

Начальный остаток каждого отдельного счёта вводится один раз с датой и основанием сверки. До его ввода показывается «Остаток не задан», не ноль. Начальный остаток не является приходом за день. Для подотчёта Шоха дата должна быть не позже первой записанной выдачи, а сумма не включать эту выдачу.

История резерва учитывает только записи до выбранной даты. Операция, создающая отрицательный резерв в этот или следующий уже записанный день, отклоняется целиком. Перевод в сейф учитывается при проверке доступных денег для всех последующих дневных расходов и выплат.

Месячная зарплата: отдельный утверждённый план наличных выплат за месяц (старый долг включён, карточные выплаты исключены), минус выплаты по именным типам месячных окладов. Дневные смены сюда не включены. План не переносится на следующий месяц и не заменяется без отдельной сверки. Это сводный план, не полноценная помесячная ведомость сотрудников.

## Границы MVP

- Новые записи находятся в существующей отдельной демонстрационной базе бухгалтера. Hikvision остаётся симуляцией.
- Апрельская ведомость не импортирована как текущие остатки. Старые неоднозначные строки дивидендов не переклассифицированы автоматически.
- Конвертация UZS ↔ USD, возврат денег из сейфа в дневную кассу и возврат Шохом наличных не реализованы. USD-поступления записываются с указанием источника; они не создают автоматический сумовый расход.
- По просьбе пользователя отдельные формы начисления, выплаты и разового исключения удалены со страницы. Зарплата вводится в общем журнале через категорию «Заработная плата» и входит в показатель выплаченного за день. Старые записи и API сохранены. Ручная строка не распределяется по индивидуальным долгам автоматически; карточка прежних подтверждённых долгов прямо предупреждает об этом.
- Дневной свободный остаток по ранее согласованной модели: «К передаче» кассира за выбранный день минус выдачи и перевод в сейф этого дня. Старый свободный сумовый остаток автоматически не переносится.
- Долг за смены, подотчёт и резервы переносятся по датам. Остаток фонда без подтверждённого начального значения не вычисляется.

## Проверки

Тесты API и хранилища проверяют раздельные валюты, отсутствие двойного списания, недостаток денег, исторический срез, запрет повторной инициализации и обратной датировки с отрицательным будущим остатком, месячные границы и запрет внешнего доступа.
