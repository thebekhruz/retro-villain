## Фаза 3 — Закуп · Шох (3a, НОВЫЙ модуль, backend + моб. UI + геймификация)

### 3.1 Роль и доступ
- Добавить роль `shokh` в `config.py` (`allowed_roles`), провижн пользователя через `DASHBOARD_PANEL_USERS`.
- Логин → по роли `shokh` отдаём мобильную страницу `retro/static/shokh.html` (fullscreen, как `ios-frame`, но без рамки).

### 3.2 Backend `retro/modules/shokh/` (routes + service + models) и таблицы в `schema.py`
- **`shokh_purchases`**: id, ts, point, item, qty, unit, price, total, photo_ref (nullable), price_flag (выше обычной), status (в норме / на проверке / принято), created_by. → появляются в 2a «Покупки наличными».
- **`shokh_cash`**: выдачи наличных Шоху (из 2a и из 5a кассира) и перечисления бухгалтера (видны Шоху как «оплачено переводом»). Баланс = Σвыдано − Σпотрачено наличными.
- **Фото:** загрузка `multipart/form-data`; хранить как файл в data-каталоге (по образцу assets) либо BLOB; отдавать по `GET /api/shokh/photo/{id}`. Ограничение размера/типа (image/*), ресайз по желанию.
- **Эндпоинты `/api/shokh/`:** `GET /home` (баланс, задания, серия, недавние, активные перечисления), `GET /catalog` (точки + типовые товары + «обычная цена»), `POST /purchase` (товар+фото+кол-во+цена, пересчёт баланса/флагов/XP), `GET /summary` (итог закупа). Бухгалтерские: `POST /api/accountant/shokh/give` (выдать наличные), `POST /api/accountant/shokh/transfer` (перечисление), `POST /api/accountant/shokh/accept/{id}` (принять покупку). (Существующий `POST /api/accountant/procurement` — переиспользовать/обернуть.)

### 3.3 Мобильный UI (`shokh.html/js/css`) — экраны из макета
Главная (hero-баланс, уровень/XP, серия дней, «Задания на сегодня», перечисления «не платить наличными», недавние покупки, кнопка «Новый закуп») → флоу из 4 шагов (точка → товар+фото → кол-во/цена с «обычной ценой» и предупреждением → подтверждение с «на руках после») → экран «Записано!» с XP → сводка закупа (время из 15:00, товаров, потрачено, опыт, уровень).

### 3.4 Геймификация (полная)
- **XP:** +30 за покупку, +10 за фото, бонус за нормальную цену, +50 за закуп <15 мин. **Уровни** (пороги XP → титул). **Серия дней** без пропусков. **Задания на сегодня** (счётчики покупок/фото). Таймер закупа.
- Правило хранения: XP/уровни/серию **вычислять из `shokh_purchases`** (не заводить отдельную таблицу состояния, где можно), задания — дневной прогресс по фактам. Пороги/титулы — константы в service.
