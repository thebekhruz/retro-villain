Операции за день

Категория → тип → наименование → сумма. Сохраните строку — остатки справа пересчитаются.

Выберите тип операции, чтобы увидеть, какой остаток изменится.

КатегорияТипНаименованиеСумма

Неоплаченные расходы

Остаток долга переносится по дням. Запишите выплату, когда действительно передали деньги.

Начальные остатки и месячная зарплатаЗаполняются один раз; апрельские суммы не переносятся на другие месяцы

Деньги у бухгалтера на старте

Введите фактический остаток на начало первого дня учёта. Далее остаток переносится автоматически.

С чего начинаем учёт

Подтверждённый остаток на начало выбранного дня, до его операций. Это не новый приход и не списание из кассы. Для Шоха укажите остаток до первой записанной выдачи.

Месячные оклады

План наличных выплат за выбранный месяц: с учётом старого долга, за вычетом выплат на карту. Авансы этого месяца, записанные здесь по именам, вычтутся автоматически.

Дневные смены в этот план не входят. Повторная запись плана блокируется.
